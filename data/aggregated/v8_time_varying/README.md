# v8_time_varying aggregated data — file guide

This directory collects aggregated results of the 1D time-dependent Burgers (V8) experiments. Conclusions such as medians are governed by **paper §7.3 and claims_provenance.csv**; this README only documents the identity of each file.

## S9 spatial-linear-family main scan (the paper's "spatial linear family control")

Format `seed,beta,L2_relative`, β∈{1,3,8,15}, seeds S0={0,5,…,50}.

- `summary.csv` / `summary_1.csv` / `summary_2.csv` / `summary_3.csv`: per-seed-β records of four full scan generations (11 rows each).
- `summary_7.csv`/`summary_8.csv`/`summary_9.csv`/`summary_10.csv`: byte-level duplicates of the four generations above (written out again during checkpoint-resume); identical content.
- `summary.json`: corresponding aggregate summary.
- `summary_4.csv`: single-row fragment (one record for seed 0), not a complete generation; kept for the record only.
- `training_log*.csv` (0–252): raw per-run training curves of the generations above.

Generating script: `code/v8_2d/experiments/time_varying/exp_S9_weighted_beta_scan.py`.

## caseB/s8 artificial bad-basin diagnosis (diagnostic-level observation in paper §7.3)

There are two seed generations: the **canonical generation (seeds 200–210)** and an early generation (seeds 0–10). The paper cites the canonical generation.

Canonical (seeds 200–210; medians: control 2.5655 / down_3 2.7495 / down_8 2.8609 / up_3 2.4433 / up_8 2.4436 / clip bitwise identical to control):

- `summary_5.csv` (=`summary_11.csv`, byte-level duplicate): control group (β=1).
- `summary_12.csv`: down_3 (spatial linear family down-weighting β=1/3 level).
- `summary_13.csv`: down_8.
- `summary_14.csv`: up_3 (mild up-weighting).
- `summary_15.csv`: up_8.
- `summary_16.csv` / `summary_17.csv` / `summary_18.csv`: clip_0.01 / clip_0.1 / control; the three are bitwise identical (clipping never triggered a change of the final state).

Early generation (seeds 0–10; numbers differ slightly, kept for the record only):

- `summary_19.csv` / `summary_20.csv` / `summary_21.csv`: clip_0.01 / clip_0.1 / control (median 2.5668).
- `summary_23.csv` / `summary_24.csv`: down_3 (2.7450) / down_8 (2.8679).
- `summary_6.csv`: partial down_3 generation (n=8, left over from an interrupted run).

Generating scripts: `caseB_zeroIC_burgers.py`, `exp_S8_zeroIC_weight_clip.py`, `exp_B1B2_zeroIC_lbfgs.py` (all in `code/v8_2d/experiments/time_varying/`).

## Other files

- `a1_condition_number_K3_N1024*.csv`: A1 condition-number measurements.
- `b3_fixed_step_lbfgs_*.csv`: B3 fixed-step L-BFGS.
- `s6*/s7*`: aggregates of the S6/S7 series (DeepXDE control and zero-initial-condition experiments).

## D1 rational-family scan (current data of paper table tab:d1beta)

Not in this directory; see `data/aggregated/v8_time_varying_d1r/` (`d1r_runs.csv` 44 rows, `d1r_mechanism_a.csv` 22 rows), generated by `exp_D1_rational_beta_scan.py`.
